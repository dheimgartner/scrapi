    PipelineResult ¶

    PipelineResult(
    results: list[ResultPair], summary: BaseInferenceResult
)

    Plain data holder for a scrapi run's results.

    Renderer-agnostic: does not know about output formats and is never mutated by a renderer.

    ResultPair ¶

    Bases: NamedTuple

    A single search result paired with its (optional) inference result.

    BaseSearchResult dataclass ¶

    BaseSearchResult(
    scraper_repr: str,
    status: SearchStatus,
    fetched_at: datetime,
    source: dict[str, str],
    raw_content: Any,
    ai_content: str,
    id: str | None = None,
    pipeline_id: str | None = None,
)

    Bases: ABC

    Every search engine must return an object of type BaseSearchResult.

    Attributes:

    Name Type Description
    id str | None

    Unique identifier for this search result (auto-generated if not provided).
    pipeline_id str | None

    Unique identifier for the pipeline run, linking search results, inference results, and summary result.
    scraper_repr str

    Corresponding search engine.
    status SearchStatus

    The fetch status.
    fetched_at datetime

    Timestamp at which the result was fetched.
    source dict[str, str]

    Depending on the search engine: e.g., {"url": "..."} for a web search engine.
    raw_content Any

    Return value of search engine's fetch_result() call.
    ai_content str

    Converted raw_content suitable for LLM consumption.

    Inference results¶

    BaseInferenceResult dataclass ¶

    BaseInferenceResult(
    prompted_at: datetime,
    system_prompt: str,
    task_prompt: str,
    structured_output: BaseModel,
    result: str,
    id: str | None = None,
    pipeline_id: str | None = None,
)

    Bases: ABC

    Every BaseSearchResult piped through an inference engine must yield an object of class BaseInferenceResult.

    Subclasses must declare the structured_output field.

    Attributes:

    Name Type Description
    id str | None

    Unique identifier for this inference result (auto-generated if not provided).
    pipeline_id str | None

    Unique identifier for the pipeline run, linking search results, inference results, and summary result.
    prompted_at datetime

    Timestamp at which the prompt was sent to the inference engine.
    system_prompt str

    System prompt supplied to the inference engine.
    task_prompt str

    Task-specific prompt supplied to the inference engine.
    structured_output BaseModel

    Structured output returned by the inference engine; shape is subclass-specific.
    result str

    Main field of structured_output.

    week_52_low float | None
