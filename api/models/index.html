    Models

    Data containers used throughout the pipeline. None of these classes perform side effects — they are plain data holders.

    RunResult

    RunResult

    Plain data holder for a scrapi run's results.

    Renderer-agnostic: does not know about output formats and is never mutated by a renderer.

    ResultPair

    ResultPair

    Bases: NamedTuple

    A single search result paired with its (optional) inference result.

    Search results

    BaseSearchResult dataclass

    Bases: ABC

    Every search engine must return an object of type BaseSearchResult.

    Attributes:

    Name Type Description
    id str | None

    Unique identifier for this search result (auto-generated if not provided).
    pipeline_id str | None

    Unique identifier for the pipeline run, linking search results, inference results, and summary result.
    scraper_repr str

    Corresponding search engine.
    status SearchStatus

    The fetch status.
    fetched_at datetime

    Timestamp at which the result was fetched.
    source dict[str, str]

    Depending on the search engine: e.g., {"url": "..."} for a web search engine.
    raw_content Any

    Return value of search engine's fetch_result() call.
    ai_content str

    Converted raw_content suitable for LLM consumption.

    WebSearchResult dataclass

    Bases: BaseSearchResult

    Search result from a web-based scraper.

    FileSearchResult dataclass

    Bases: BaseSearchResult

    Search result from a local file scraper.

    FinanceSearchResult dataclass

    Bases: BaseSearchResult

    Search result from the finance scraper.

    Unlike other result types, raw_content is a FinancialSnapshot instead of a raw string.

    SQLSearchResult dataclass

    Bases: BaseSearchResult

    Search result from the SQL scraper.

    raw_content is a list[dict] where each dict represents one row.

    Search status

    SearchStatus dataclass

    Bases: ABC

    Base class for fetch status codes.

    SuccessfulSearch dataclass

    Bases: SearchStatus

    Indicates a successful fetch (HTTP 200 or equivalent).

    FailedSearch dataclass

    Bases: SearchStatus

    Indicates a failed fetch.

    Attributes:

    Name Type Description
    error Exception | None

    The exception that caused the failure, if any.

    FinancialSnapshot

    FinancialSnapshot dataclass

    Investor-relevant financial data for a single ticker fetched via yfinance.

    Attributes:

    Name Type Description
    ticker str

    Stock ticker symbol (e.g. "AAPL").
    fetched_at datetime

    Timestamp of the data fetch.
    name str | None

    Company name.
    sector str | None

    Business sector.
    industry str | None

    Industry classification.
    currency str | None

    Reporting currency.
    current_price float | None

    Latest traded price.
    previous_close float | None

    Previous session closing price.
    market_cap float | None

    Total market capitalisation.
    pe_ratio float | None

    Trailing price-to-earnings ratio.
    forward_pe float | None

    Forward price-to-earnings ratio.
    eps float | None

    Trailing twelve-month earnings per share.
    revenue float | None

    Trailing twelve-month total revenue.
    profit_margin float | None

    Net profit margin (0–1).
    dividend_yield float | None

    Annual dividend yield (0–1).
    beta float | None

    5-year monthly beta vs. S&P 500.
    week_52_high float | None

    52-week high price.
    week_52_low float | None

    52-week low price.
    analyst_target_price float | None

    Median analyst 12-month price target.
    recommendation str | None

    Analyst consensus recommendation (e.g. "buy").
    info dict

    Raw yfinance info dict for any fields not explicitly captured.
